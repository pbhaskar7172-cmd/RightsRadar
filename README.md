# RightsTrack Yojna 🏛️⚖️

> **Statutory Citizen Rights & Action Radar System**
> Empowering Indian citizens with proactive statutory grievance tracking, legal notice drafting, mandatory response countdowns, and multi-tier appellate escalation.

---

## 🌟 Key Features

- **Editorial Pastel Interface**: Clean, warm off-white canvas with pastel accent containers, high-contrast dark typography, spring micro-interactions, and top horizontal pill navigation.
- **Statutory Action Radar**: Real-time statutory tracking with radar sweep visuals and mandatory response window countdowns.
- **5-Step Grievance Intake Wizard**:
  1. *Category & Claim Identification* (RTI Act 2005, Consumer Protection Act 2019, Model Tenancy Act, etc.)
  2. *Interactive Synthesis Wizard* (Dynamic multi-step questions tailored to the grievance)
  3. *Statutory Legal Diagnosis* (Identifies governing statute, jurisdiction, and enforceable rights)
  4. *Legal Notice Drafting Simulator* (Realistic formal legal paper preview with editable text and printable export)
  5. *Dispatch Proof & Clock Activation* (Logs Speed Post barcodes or portal ACK numbers to start statutory clocks)
- **Comprehensive Case Hub**: 4-tab case details hub including 8-stage milestone timeline, formal legal documents, evidence locker, and appellate escalation tiers.
- **Evidence Vault**: Categorized evidence locker (payment proofs, notice slips, tenancy deeds, chat logs) with inline inspection modals.
- **Statutory Knowledge Base**: Reference library of Indian statutory acts, procedural rules, and official gazetted portals.
- **Citizen Persona Switcher**: Instant 1-click demo persona toggle (*Ananya Sharma*, *Rajesh Patel*, *Vikram Malhotra*).

---

## 🛠️ Tech Stack

- **Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS with custom editorial design system tokens
- **Animations**: Framer Motion (spring layouts, smooth page transitions, radial radar sweeps)
- **Icons**: Lucide React
- **Build Tool**: Vite

### 3. Build for Production

## 📜 Governing Statutes Supported

- **Right to Information Act, 2005** (Section 6(1) & First Appeal under Section 19(1))
- **Consumer Protection Act, 2019** (Sections 2(7), 35, and CPA Notice Rules)
- **Model Tenancy Act / State Rent Control Acts** (Section 15, Mandatory Security Deposit Return)
- **Citizen Delivery of Public Services Acts** (Mandated Service Delivery Windows)
